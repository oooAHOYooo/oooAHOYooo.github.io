AHOY Streamer TUI

A keyboard driven terminal listening room for discovering and playing independent media from AHOY Streamer.

Browse music, videos, podcasts, artists, events, Studio, Radio, AHOY TV, and Search. Play supported audio and video in the terminal. A small JSON command interface is also available for scripts and agents. The setup steps below get you running on Linux, macOS, or Windows.

Who it’s for

For listeners who enjoy keyboard-driven apps and are comfortable opening a terminal. Its JSON commands also suit scripts and agents.

What you need

Python 3.11 or newer and an internet connection to browse the public catalog. Real device playback has not yet been manually verified.

Status: Early testing draft · Python package not published · Linux quick installer · macOS and Windows setup below

Get started

Pick your computer below. The TUI is still in early testing, so these steps install it from the public source repository.

Linux · quick install

Open a terminal, run the installer, then launch the app:

curl -fsSL https://raw.githubusercontent.com/oooAHOYooo/ahoy-streamer-cli/main/install.sh | bash
~/.local/bin/ahoy-streamer

The installer creates an isolated Python environment. If Git or Python setup tools are missing, it asks before installing system prerequisites.

macOS · install from source

Requires Python 3.11 or newer and Git. In Terminal, run:

git clone --branch main --single-branch https://github.com/oooAHOYooo/ahoy-streamer-cli.git
cd ahoy-streamer-cli
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
ahoy-streamer

macOS 13 or newer supports the experimental terminal video renderer by default. On macOS 12 and older, videos open in a browser.

Windows · install from source

Requires Python 3.11 or newer and Git. Open PowerShell and run:

git clone --branch main --single-branch https://github.com/oooAHOYooo/ahoy-streamer-cli.git
cd ahoy-streamer-cli
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
ahoy-streamer

Terminal video is silent on Windows. The setup guide covers playback controls and optional media dependencies.

Audio and video support varies by format and system. See the full setup and troubleshooting notes on GitHub ↗.
