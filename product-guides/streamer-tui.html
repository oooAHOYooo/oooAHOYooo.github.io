Keyboard driven TUI · macOS, Windows, and Linux

AHOY Streamer TUI

Discover independent music and video from AHOY Streamer in a keyboard-driven terminal.

Explore artists, events, Studio, Radio, and AHOY TV too. JSON commands let scripts and agents use the same catalog.

Works today

Browse and search the public catalog, open item details, and use the keyboard interface or JSON commands.

Playback status

Audio and video playback are implemented, but real device playback is still being verified across systems.

What you need

An internet connection to browse the catalog. The standalone downloads bundle Python; Homebrew is the shortest Mac install.

Known limits

Video soundtracks need optional mpv on Mac and Linux. Terminal video on Windows is silent. The Mac preview is unsigned and may need Gatekeeper approval.

Install with Homebrew

On macOS 13 or newer, install the preview with one command. Homebrew adds the AHOY tap automatically; Python is not required.

brew install oooAHOYooo/ahoy-streamer/ahoy-streamer

Update with brew upgrade ahoy-streamer or remove it with brew uninstall ahoy-streamer. This is an unofficial project tap.

Start listening

  1. Extract the ZIP you downloaded.
  2. Open Terminal or PowerShell in the extracted folder.
  3. Run the command for your system:

Mac or Linux

./ahoy-streamer

Windows PowerShell

.\ahoy-streamer.exe

If Mac or Linux says “permission denied,” run chmod +x ahoy-streamer once and try again. If Gatekeeper blocks the unsigned Mac preview, follow Apple’s opening guide.

Advanced: install from source

Use these if you need Linux ARM or prefer a source install. They need an internet connection, Python 3.11 or newer, and Git; the standalone ZIPs include Python and need fewer prerequisites.

macOS or Linux (Terminal)

curl -fsSL https://raw.githubusercontent.com/oooAHOYooo/ahoy-streamer-cli/main/install.sh | bash
~/.local/bin/ahoy-streamer

The installer also needs Git and Python’s venv/pip. On supported Linux systems it offers to install missing packages. On a Mac, install Python 3.11+ and run xcode-select --install if Git is missing. Paste the first line again to update. Uninstall with ~/.local/bin/ahoy-streamer-uninstall.

Windows 10/11 (PowerShell)

$app = Join-Path $env:LOCALAPPDATA 'AHOY Streamer'
py -3 -m venv $app
if ($LASTEXITCODE -ne 0) { throw 'Python 3.11+ with venv is required.' }
& (Join-Path $app 'Scripts\python.exe') -m pip install --disable-pip-version-check --upgrade 'https://github.com/oooAHOYooo/ahoy-streamer-cli/archive/refs/heads/main.zip'
if ($LASTEXITCODE -ne 0) { throw 'Install failed; check the error above.' }
& (Join-Path $app 'Scripts\ahoy-streamer.exe')

If py -3 --version fails, install Python 3.11+ first. Paste the same block again to update. Later, launch with & (Join-Path $env:LOCALAPPDATA 'AHOY Streamer\Scripts\ahoy-streamer.exe').

The GitHub setup guide has additional troubleshooting and platform notes.
