AHOY Player CLI

Scan, organize, and play a local music library from a terminal, with a text based player.

This tool is for people comfortable with a terminal. It needs Node.js 20 or newer. macOS and Linux support playback; Windows supports library commands and the text interface.

Who it’s for

For people who prefer managing and playing a local music collection from a terminal.

What you need

Node.js 20 or newer. Playback works on macOS and Linux; Windows supports library commands and the text interface.

Status: Available as a Node.js package · version 0.2.3 release asset.

Install AHOY Player CLI

With Node.js 20 or newer installed, open Terminal or PowerShell and run:

npm install --global https://github.com/oooAHOYooo/ahoy-player/releases/download/v0.2.3/ahoy-player-terminal-0.2.3.tgz
Download package (.tgz)

Then run ahoy scan ~/Music and ahoy player. On Windows, use your music folder path in place of ~/Music.
