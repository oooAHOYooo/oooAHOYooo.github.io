02 / one person’s path

The loop that should work

Before adding more products, this is the smallest complete relationship to make reliable.

01

Arrive

Someone lands on the public front door.

02

Enter

The bundled app loads its shell and data.

03

Discover

They browse or search independent work.

04

Play

The player points at an audio/video URL.

05

Save

A like or preference creates a reason to return.

06

Own later

A future entitlement makes access durable.

What is connected now?

The static site, bundled web app, local JSON collections, native media players, browser persistence, and Firebase wiring exist in the repository. Remote data behavior depends on each feature’s configured source.

What is not connected yet?

A real marketplace backbone: payment verification, entitlement records, signed downloads, offline packages, creator payouts, and cross-device sync. Those should be designed as one trust layer.
